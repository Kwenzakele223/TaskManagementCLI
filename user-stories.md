# USER STORIES

1. **Create a Task**
   As a user,
   I want to create a task,
   so that it can be added to my task list.

2. **View Tasks**
   As a user,
   I want to view my tasks,
   so that I can see all the tasks I have created.

3. **Delete a Task**
   As a user,
   I want to delete a task from my task list,
   so that it no longer appears when I view my tasks.

4. **Complete a Task**
   As a user,
   I want to mark a task as complete,
   so that I can see which tasks are completed and which are not.

5. **Exit the Application**
   As a user,
   I want to exit the application,
   so that the Task Management CLI can close properly.

6. **Save Task Data**
   As a user,
   I want my task data to be saved,
   so that it can be stored in the JSON file and loaded again when I use the application.

7. **Delete All Tasks**
   As a user,
   I want to delete all my tasks,
   so that my task list will be empty.
