# Assumptions

The following assumptions are made for the Task Management CLI:

1. The user has Java installed and can run Java applications.

2. The user has access to a terminal or command line.

3. The user has permission to create and use the SQLite database file.

4. The user will provide the correct information when registering and logging in.

5. Each user will use a unique username.

6. A user must log in before managing their tasks.

7. Each task belongs to one user.

8. Users should only manage their own tasks.

9. The SQLite database will be available when the application is running.

10. The application is mainly intended for learning and small-scale use.

11. Users are expected to understand basic terminal instructions.

12. The requirements of this version only cover user management and task management.
