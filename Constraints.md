# Constraints

The following constraints apply to the Task Management CLI:

## 1. Command-Line Application

* The application is used through the terminal.
* There is no graphical user interface.

## 2. SQLite Database

* The application uses SQLite as its database.
* It is designed for a small-scale project and not a large production system.

## 3. Single Application Instance

* The current version is designed to be used through the CLI rather than as a web application.
* It does not provide a web interface or mobile application.

## 4. User Authentication

* Users must register and log in before managing their tasks.
* The current authentication system is basic and is intended for learning purposes.

## 5. Task Information

* The current version only supports the task information included in the project requirements.
* Advanced task features such as categories, deadlines, priorities, or reminders are not included.

## 6. Internet Connection

* The application does not require an internet connection to manage users and tasks.
* The application works with the local SQLite database.

## 7. Project Scope

* The project focuses on user management and task management.
* Features outside the project requirements are not included in this version.
